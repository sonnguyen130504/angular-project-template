# Page Map

This template includes routed pages meant for quick reference and immediate reuse in commerce and product-style apps.

## Pages

- `Home`: template index with links into commerce, product UI, and reference groups.
- `Dashboard`: operations overview with metrics, PrimeNG chart, table, progress, activity, and toast feedback.
- `Component gallery`: docs-style controls, feedback, navigation, overlays, skeleton, and loading patterns.
- `Forms`: validation, date picker, select, slider, toggles, notes, and review summary.
- `Data visualization`: PrimeNG charts, legends, metrics, and table detail.
- `Motion lab`: state motion, loading, and reveal reference patterns.
- `Catalog`: filterable listing with search, category, sort, grid/list view, and pagination.
- `Product`: detail page with gallery, variants, quantity, delivery, fit notes, and recommendations.
- `Cart`: checkout layout with item state, quantity, promo, totals, removal, and empty state.
- `Settings`: account preferences with tabs, toggles, preview, security, and danger zone.
- `Sign-in`: auth entry point with validation and recovery path.
- `Forgot password`: password reset flow with confirmation state.
- `Empty state`: reusable no-data pattern with next actions.
- `Profile`: user account overview with details, orders, sessions, and stats.
- `Not found`: fallback route and 404 pattern.

## How to use

- Keep the current page as a reference.
- Copy the structure that fits your use case.
- Replace placeholder content only after the layout pattern is clear.
- Extract shared UI only when the same pattern appears in more than one page.
